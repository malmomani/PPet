# Maya Android App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Maya's body on the phone: an APK that shows her as a floating pixel sprite over other apps, connects to the PC brain over WebSocket, reports which app is in use, and shows her speech bubbles and animations.

**Architecture:** Two Gradle builds under `android/`. `core` is a pure Kotlin/JVM library holding all logic worth testing (protocol, offline queue, backoff, app-usage tracking, do-not-watch filter, sprite config, behavior state machine); it builds and tests locally with plain Gradle. `app` is the Android application (service, overlay views, senses, settings) that depends on `core` through a composite build (`includeBuild("core")`) and is built only in GitHub Actions, which uploads the debug APK. The app layer stays thin: it adapts Android APIs to `core` interfaces.

**Tech Stack:** Kotlin 2.0.21, Gradle 8.14.3 (wrapper), Android Gradle Plugin 8.7.3, JDK 17 in CI (JDK 21 locally is fine for `core`), kotlinx-serialization-json 1.7.3, OkHttp 4.12.0, JUnit 4.13.2. No other runtime dependencies.

**Spec:** `docs/superpowers/specs/2026-10-24-maya-design.md` — §6 (Android) and §4 (protocol). The brain's actual protocol is `brain/maya_brain/protocol.py`; it is the source of truth for field names.

## Global Constraints

- `applicationId`/namespace `com.maya.app`; core package `com.maya.core`. `minSdk 29`, `targetSdk 35`, `compileSdk 35`.
- Build layout: `android/core/` (standalone Gradle build with its own `settings.gradle.kts`, Kotlin JVM + serialization plugins), `android/` root build containing `:app` and `includeBuild("core")`. Gradle wrapper lives in `android/` (8.14.3) and is copied/used for `core` too (`android/core/gradlew` not needed: run `../gradlew -p core` or local `/opt/gradle/bin/gradle`).
- Local verification for `core`: `cd android/core && gradle test` (Google's Maven/SDK hosts are blocked in the dev sandbox; never try to build `:app` locally). `:app` verification = the `android` GitHub Actions workflow on push is green and uploads `maya-debug-apk`.
- Protocol must match the brain exactly. Events sent: `hello{client_version, screen_w, screen_h}`, `user_message{text 1..2000}`, `user_tap{}`, `user_drag{thrown}`, `user_shush{}`, `app_opened{package,label}`, `app_closed{package,label,duration_s>=0}`, `screen{on}`, `charging{on}`, `offline_summary{events: [objects], since}`. Actions received: `say{text,bubble_ms}`, `animate{name}`, `state{mood,closeness_tier}`, `typing{on}`, `error{code,message}`; unknown types ignored. Every message has `type`, `id` (UUID string), `ts` (ISO-8601 UTC, e.g. `2026-10-24T14:00:00Z`).
- Animation names: `idle, walk, sit, nap, wave, peek, happy, sulk, surprised`.
- WebSocket URL: `ws://<host>:<port>/ws?token=<token>`; default port `8765`. Reconnect backoff 1 s doubling to max 60 s, reset after a successful open. Offline queue capacity 200, oldest dropped. App usage poll every 5 s.
- Cleartext `ws://` to LAN/Tailscale must work: `android:usesCleartextTraffic="true"` in the manifest.
- Foreground service type `specialUse` (Android 14+) with `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_SPECIAL_USE`, `POST_NOTIFICATIONS`, `SYSTEM_ALERT_WINDOW`, `PACKAGE_USAGE_STATS` (tools:ignore ProtectedPermissions), `RECEIVE_BOOT_COMPLETED`, `INTERNET` permissions; `PROPERTY_SPECIAL_USE_FGS_SUBTYPE` = `"Companion character overlay"`.
- Never log the token. No analytics, no network calls other than the configured brain address.
- Sprites: sheet `app/src/main/assets/sprites/maya.png` + `app/src/main/assets/sprites/sprites.json`; placeholder art generated by `android/tools/make_placeholder_sprites.py` (Python stdlib only). Real art replaces these two files.

## Review Focus

1. **PC unreachable / wrong token / brain restarting** → Maya naps, no crash, no tight reconnect loop; app events queue (≤200) and arrive as one `offline_summary`. (Tests: Task 3 `backoff_doubles_and_caps`, `queue_drops_oldest_and_summarizes`; Task 8 handles `error{code:"auth"}` by stopping reconnects and showing "Check token" in the notification.)
2. **Do-not-watch and launcher apps** → banking/password apps and the home screen never appear as `app_opened`, but still close the previous app. (Test: Task 4 `ignored_package_closes_previous_without_opening`.)
3. **Touches outside Maya reach the app below; tap vs drag vs fling are told apart.** (Test: Task 5 `gesture_classifier_*` in core; overlay window sized to the sprite in Task 9.)
4. **Malformed or unexpected brain messages** (unknown type, unknown animation, missing fields) → ignored, no crash. (Test: Task 2 `decode_unknown_and_malformed_returns_null`, `unknown_animation_maps_to_idle`.)
5. **Android killing or restricting the service** (boot, Samsung battery optimization, revoked overlay/usage permission) → restarts on boot, settings screen shows each permission's state with a button to fix it; a revoked permission doesn't crash the service. (Task 7 settings status; Task 8 guards `canDrawOverlays` before adding views.)

### Task 2: Protocol (core)

**Files:** Create `core/src/main/kotlin/com/maya/core/Protocol.kt`; Test `core/src/test/kotlin/com/maya/core/ProtocolTest.kt`

**Interfaces:**
- Produces:
  - `sealed interface Event { val id: String; val ts: Instant }` with data classes `Hello(clientVersion, screenW: Int, screenH: Int)`, `UserMessage(text)`, `UserTap`, `UserDrag(thrown: Boolean)`, `UserShush`, `AppOpened(packageName, label)`, `AppClosed(packageName, label, durationS: Long)`, `Screen(on)`, `Charging(on)`, `OfflineSummary(events: List<Event>, since: Instant)`. Each constructor takes `id: String = newId()`, `ts: Instant = Instant.now()` last. (`java.time.Instant`.)
  - `sealed interface Action` with `Say(text, bubbleMs: Long)`, `Animate(name: String)`, `State(mood, closenessTier)`, `Typing(on)`, `ErrorMsg(code, message)`.
  - `object Protocol { fun encode(e: Event): String; fun encodeObject(e: Event): JsonObject; fun decodeAction(text: String): Action? }`.
  - `val ANIMATIONS: List<String>` (Global Constraints order).
- JSON keys are snake_case exactly as the brain (`client_version`, `screen_w`, `package`, `duration_s`, `bubble_ms`, `closeness_tier`). Build JSON with `buildJsonObject` (no reflection-heavy polymorphism needed); `ts` formatted with `DateTimeFormatter.ISO_INSTANT`.

### Task 4: Do-not-watch and app-usage tracking (core)

**Files:** Create `DoNotWatch.kt`, `AppUsageTracker.kt`; Test `DoNotWatchTest.kt`, `AppUsageTrackerTest.kt`

**Interfaces:**
- Produces:

Durations use whole seconds, never negative.
  - The app passes `isIgnored = { doNotWatch.isBlocked(it) || it in launchers || it == ownPackage }`.

### Task 5: Sprite config, gestures, behavior state machine (core)

**Files:** Create `SpriteConfig.kt`, `Gestures.kt`, `Behavior.kt`; Test `SpriteConfigTest.kt`, `GesturesTest.kt`, `BehaviorTest.kt`

**Interfaces:**
- Produces:
  - `data class AnimSpec(row: Int, frames: Int, fps: Int, loop: Boolean)`; `data class SpriteConfig(frameW: Int, frameH: Int, animations: Map<String, AnimSpec>) { fun spec(name: String): AnimSpec }` (unknown/missing name → `idle`'s spec); `fun parseSpriteConfig(json: String): SpriteConfig` — format `{"frame_w":32,"frame_h":32,"animations":{"idle":{"row":0,"frames":4,"fps":4,"loop":true},…}}`; throws `IllegalArgumentException` if `idle` is missing or any value ≤ 0.
  - `enum class Gesture { TAP, DRAG, FLING }`; `fun classifyGesture(distancePx: Float, durationMs: Long, releaseSpeedPxPerS: Float, touchSlopPx: Float): Gesture` — `distance < touchSlop && duration < 300` → TAP; `releaseSpeed > 2500` → FLING; else DRAG.
  - `class Behavior(screenW: Int, spriteW: Int, rng: Random, speedPxPerS: Float)` with `val animation: String`, `val x: Float`, `val facingLeft: Boolean`, `fun tick(dtMs: Long)`, `fun play(name: String)`, `fun setConnected(on: Boolean)`, `fun dragStart()`, `fun dragEnd(x: Float)`.
    - Rules: starts `idle` at `x = screenW - spriteW` (bottom-right corner; y is the view's concern). Disconnected → `nap` until connected (ignores `play` except while connected). Every decision point (uniform 3000..8000 ms of idle) chooses: walk 40 % for 2000..6000 ms, sit 25 % for 5000..15000 ms, idle 35 %. Walking moves `speed × dt`, clamps to `[0, screenW - spriteW]`, turns around at an edge. `play(name)` shows that animation for 2500 ms then returns to `idle` (`walk`/`sit`/`nap`/`idle` via `play` just switch state immediately with their normal durations). While dragged: animation `surprised`, no movement; `dragEnd(x)` sets x (clamped) and returns to `idle`.

### Task 10: Overlay body, bubble and chat (app)

- Produces:

  - `SpriteView` draws the current frame scaled ×4 with nearest-neighbour (`Paint.isFilterBitmap = false`), mirrored when `facingLeft`; advances frames by the spec's fps (`loop=false` holds the last frame).
  - `OverlayBody(context, emit: (Event) -> Unit)`: `fun show()`, `fun hide()`, `fun handle(a: Action)`, `fun setConnected(on: Boolean)`. One `WindowManager` view (`TYPE_APPLICATION_OVERLAY`, `FLAG_NOT_FOCUSABLE | FLAG_LAYOUT_NO_LIMITS`, size = sprite only, gravity top-left, y = screen height − sprite height − 48 dp) moved by a 30 fps `Choreographer`/`Handler` loop driving `Behavior.tick`. Touch: track down/move/up with `VelocityTracker`; while moving beyond touch slop → `behavior.dragStart()` and follow the finger (x and y); on up → `classifyGesture`: TAP → `emit(UserTap())` and open `ChatWindow`; DRAG → `dragEnd(x)`, keep y, `emit(UserDrag(false))`; FLING → animate a short throw in the fling direction (≤ 400 ms, clamped to screen), then `dragEnd`, `emit(UserDrag(true))`.

  - `ChatWindow`: a focusable overlay window (`TYPE_APPLICATION_OVERLAY` without `FLAG_NOT_FOCUSABLE`) with an `EditText` + Send; Send emits `UserMessage(text.trim().take(2000))` if non-blank and closes; back/outside-tap closes.
  - Service: create `OverlayBody` only if `Settings.canDrawOverlays`; `Hide` action toggles `show/hide`.
